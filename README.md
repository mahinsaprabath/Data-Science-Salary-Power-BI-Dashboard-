# 📊 Data Science Salaries Dashboard  

An interactive **Power BI dashboard** analyzing global **Data Science salaries** across job titles, locations, company sizes, and experience levels.  
This project helps professionals, students, and organizations explore salary trends and make informed career or hiring decisions.  

---

## ✨ Features  
✔️ Salary trends over time (2020–2023)  
✔️ Salary comparison by **job title**, **company size**, and **experience level**  
✔️ Global company locations visualized on a map  
✔️ Job popularity across different roles  
✔️ Key insights at a glance:
   - **Number of Job Titles**: 93  
   - **Number of Employers**: 3,755  
   - **Average Salary**: $137.57K
